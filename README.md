# TechCrunch Website (HTML Practice Project)

## About This Project
This is my second HTML project and part of the beginning of my coding journey.
I built it using only HTML to practice the basics. I'm still learning,
and I plan to add CSS and more features as I go.

## Description
A recreation of a TechCrunch news page built with HTML only. It includes a top menu with navigation links and a news article about Microsoft's plan to buy Activision Blizzard for $68.7 billion.

## Features
- Top menu with navigation links (Login, Search, Startups, TechCrunch+, Audio, Newsletters, Videos, Advertise, Events, More)
- "Join TechCrunch+" text
- News article: "Microsoft to buy Activision Blizzard for $68.7 billion"
- Author byline (Amanda Silbering)
- Article image with alt text

## HTML Concepts Practiced
- `<section>` to group related content
- Headings (`<h1>`, `<h4>`)
- Unordered lists (`<ul>`, `<li>`)
- Links (`<a href="">`)
- Images (`<img src="" alt="">`)
- Inline text (`<span>`)

## How to Run
1. Download or clone this project.
2. Open `index.html` in any web browser.
